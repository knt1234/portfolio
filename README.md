# ポートフォリオ

AIを使って、業務アプリ、比較資料、案内チラシなど、どのようなものを形にできるかを伝えるポートフォリオです。掲載物をそのまま提供するのではなく、「こんなものも作れる？」という相談のきっかけになることを目的にしています。

**公開URL**: https://knt1234.github.io/portfolio/

## 収録しているもの

| できること | 制作例 |
|---|---|
| 定型書類の作成と管理 | 請求書・見積書・申請書などを入力からPDF発行まで自動化 |
| 一覧から書類を一括作成 | 領収書・証明書・案内状などをまとめて生成 |
| 計画と実績の一元管理 | 予算・案件収支などを複数人で更新・比較 |
| 届いた情報の集計と可視化 | メール・明細・報告データを自動分類してグラフ化 |
| 案内チラシの制作 | ホテル・施設・サービスのURLから情報と画像を取得して構成・デザイン |
| 比較チラシの制作 | スポーツ・イベント・商品の複数URLから比較軸を設計してデザイン |

## デモについての注意

このリポジトリに入っている業務アプリは **すべてデモ用のコピー** です。チラシはポートフォリオ用の制作物です。

- 表示されるデータは **すべて架空** です。実在の個人・企業・取引・金額とは一切関係ありません
- ログインは不要です。データはサーバーに送られず、閲覧している方のブラウザ内だけに保存されます
- 各デモの「初期状態に戻す」ボタンで、いつでも最初の状態に戻せます
- 実運用しているアプリとは別物で、本番の接続情報・実データは一切含まれていません

## 技術的な構成

すべて **ビルド不要の静的HTML** です。サーバーもデータベースも使っていないため、
GitHub Pages に置くだけで動作します。

- 請求書 / 領収書: HTML + JavaScript（jsPDF によるPDF生成、localStorage 保存）
- イベント収支: 実運用版は Firebase Authentication + Cloud Firestore。
  デモ版では `firebase-mock.js` がその両方を肩代わりしており、
  アプリ本体（約3,000行）は無改造のまま動作します
- クレカダッシュボード: 素の SVG で描画（グラフライブラリ不使用）
- チラシ: HTML / CSSでA4レイアウトを設計し、PNGとPDFに書き出し
