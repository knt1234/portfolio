PORTFOLIO

自分の業務を、自分で作って軽くする。

毎月くり返していた手作業を、その都度Webアプリにしてきました。 ここに置いてあるのは、実際に業務で使っているものを、 架空のデータに入れ替えたデモ版です。ログイン不要で、そのまま触れます。

請求書作成

Invoice Studio

課題
毎月、前月の請求書ファイルを複製して日付と金額を書き換えていた。源泉徴収税の計算を手でやるため、たまに間違える。
つくったもの
取引先を登録しておけば、選んで品目を入れるだけで請求書ができる。源泉徴収税・複数税率・インボイス経過措置の控除まで自動計算し、そのままPDFに書き出す。発行履歴から入金済み／未入金も追える。
  • HTML / CSS / JavaScript
  • jsPDF
  • localStorage
  • ビルド不要

領収書発行

Receipt Generator

課題
入金一覧を見ながら、領収書を1枚ずつ作っていた。月末に数十枚たまると半日仕事になる。
つくったもの
入金明細のテキストを貼り付けると、日付・氏名・金額・支払方法を読み取ってまとめて作成。A4に2枚ずつ並べた1つのPDFで出力し、そのまま印刷して切るだけにした。発行会社ごとにインボイス登録番号と但し書きを切り替えられる。
  • HTML / CSS / JavaScript
  • html2canvas
  • jsPDF
  • Firebase Auth（実運用版）
デモを開く

イベント収支管理

Event Budget

課題
合宿の見積もりをスプレッドシートで作っていたが、2人で編集すると数式が壊れ、どれが最新か分からなくなっていた。
つくったもの
宿泊・食事・会場などの条件を変えたプランを何案も作り、収支と損益分岐人数を並べて比較。採用した案を予算として固定し、開催後に実績を入れて差額を見る。2人が同時に開いても、入力した内容がすぐ相手の画面に反映される。
  • HTML / CSS / JavaScript
  • Firebase Authentication
  • Cloud Firestore
  • Firebase Hosting
デモを開く

クレカ月次支出ダッシュボード

Card Spending Dashboard

課題
カード4枚の請求メールがバラバラに届くうえ、締め日も支払日も会社ごとに違う。結局ひと月にいくら使っているのか把握できていなかった。
つくったもの
請求メールを自動で集計し、「支払月」に基準をそろえて4枚を積み上げグラフで可視化。締め日がずれるカードは支払月に合わせて計上をずらしている。店舗名からのカテゴリ別内訳と、毎月くり返される定額課金の自動検出も付けた。
  • HTML / CSS / JavaScript
  • SVG（グラフライブラリ不使用）
  • メール自動集計
デモを開く

デモについて

  • 表示される会社名・氏名・金額・取引はすべて架空です。実在の個人・企業・取引とは関係ありません。
  • ログインは不要です。入力した内容はサーバーに送られず、ご覧の端末のブラウザ内だけに保存されます。
  • 各デモの上部にある「初期状態に戻す」で、いつでも最初のサンプルに戻せます。
  • 実運用しているアプリとは別のコピーで、本番の接続情報や実データは含まれていません。
