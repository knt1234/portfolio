つくったもの

毎月くり返していた手作業を、
ひとつずつアプリにしました。

請求書づくり、領収書の発行、イベントのお金の管理、クレジットカードの支出把握。 どれも「面倒だな」と思いながら毎月やっていたことです。 ここに置いてあるのは、実際に仕事で使っているものを、 中身を架空のデータに入れ替えたお試し版。 登録もログインも要りません。押せば、そのまま動きます。

請求書づくり

毎月の請求を、選ぶだけに

困っていたこと
毎月、前の月の請求書ファイルをコピーして、日付と金額を書き換えていました。税金の差し引きを電卓で計算するので、たまに間違えます。
こうした
取引先を一度登録しておけば、あとは選んで金額を入れるだけ。消費税と源泉徴収の差し引きまで自動で計算して、そのまま印刷できる形で書き出します。出した請求書は一覧に残り、入金が済んだかどうかもひと目で分かります。
  • 印刷できる形で書き出し
  • 税金の計算は自動
  • 入金の管理
  • スマホでも使える
使っている技術

HTML / CSS / JavaScript のみ。PDF生成に jsPDF、保存はブラウザの localStorage。ビルド工程なしの静的ファイル1枚で完結。

領収書の発行

数十枚を、貼り付けて一度に

困っていたこと
入金の一覧を見ながら、領収書を1枚ずつ作っていました。月末に数十枚たまると、それだけで半日つぶれます。
こうした
入金の一覧をコピーして貼り付けるだけで、必要な枚数をまとめて作ります。A4の紙に2枚ずつ並んだ形で出てくるので、印刷して切るだけ。会社名や但し書きは、発行元ごとに切り替えられます。
  • 貼り付けて一度に作成
  • 印刷してすぐ渡せる
  • 発行元ごとに切り替え
使っている技術

HTML / CSS / JavaScript。画面を html2canvas で画像化し jsPDF で1つのPDFに結合。実際に使っている版は Firebase Authentication で利用者を限定。

イベントのお金の管理

黒字になる案を、見比べて決める

困っていたこと
合宿の見積もりを表計算ソフトで作っていましたが、2人で同時に触ると計算式が壊れ、どれが最新か分からなくなっていました。
こうした
宿の部屋数や食事の回数を変えた案を何通りか作り、「どの案なら黒字か」「何人集まれば元が取れるか」を並べて見比べられます。案をひとつ決めたら予算として固定し、終わったあとに実際かかった額を入れて差を確認。2人が同時に開いても、片方の入力がすぐもう片方の画面に出ます。
  • 案を並べて見比べ
  • 何人で元が取れるか計算
  • 2人で同時に編集
  • 自動で保存
使っている技術

Firebase Authentication（Googleログイン）＋ Cloud Firestore ＋ Firebase Hosting。onSnapshot による購読でリアルタイム同期。アプリ本体は約3,000行。

カードの支出をひと目で

4枚をまとめて、月ごとに

困っていたこと
カード4枚の請求メールがバラバラに届くうえ、締め日も引き落とし日も会社ごとに違います。結局ひと月にいくら使っているのか、分からないままでした。
こうした
届いた請求メールを自動で読み取って集計し、「実際に引き落とされた月」にそろえてグラフにしました。締め日がずれるカードも、引き落としの月に合わせて数えています。何にいくら使ったかの内訳と、毎月自動で引き落とされている定額サービスの洗い出しも出ます。
  • メールから自動で集計
  • グラフで見える化
  • 使い道の内訳
  • 定額サービスの洗い出し
使っている技術

グラフ描画ライブラリを使わず、素の SVG を JavaScript で組み立て。メールからの抽出・集計は別途スクリプトで実行し、結果をこの画面に流し込む構成。

お試し版について

  • 出てくる会社名・人の名前・金額はすべて架空です。実在の人や会社、実際の取引とは関係ありません。
  • ログインは要りません。入力した内容がどこかに送られることはなく、ご覧の端末の中だけに残ります。
  • 画面の上にある「初期状態に戻す」を押せば、いつでも最初のサンプルに戻ります。自由に触ってみてください。
  • 仕事で実際に使っているものとは別のコピーです。本物のデータは一切入っていません。
